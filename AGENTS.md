# Mod guidance
- Keep starting unit XP at 40000 and combat XP at +40000%; these values are intentional.
- Keep Great General and Great Admiral earned-rate modifiers at [-99]% faster; gate the Admiral modifier on `Civ V - Gods & Kings`.
- Do not reduce unit XP to address Great Person generation rates.
- Validate JSON with `python3 -m json.tool jsons/Buildings.json >/dev/null`.
- Check whitespace with `git diff --check`.
